Use widgetctl in a CI pipeline

This section shows how to authenticate widgetctl in a CI pipeline without storing a password.

Authenticate in CI

Use the example script below to sign in, cache the session, and confirm the sign-in worked.

This pipeline does the following:

  • Installs the latest widgetctl release.
  • Restores a cached session when one exists.
  • Signs in with the token and caches the new session.
  • Confirms the sign-in with widgetctl whoami.

Before you use this script

  • Add a token named WIDGETCTL_TOKEN to your CI secrets.
  • Tokens expire after 90 days; rotate the secret before then.
