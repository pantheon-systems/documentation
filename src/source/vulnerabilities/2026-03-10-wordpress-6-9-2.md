## What is the vulnerability?

[WordPress 6.9.2](https://wordpress.org/news/2026/03/wordpress-6-9-2-release/) is a security release. [WordPress 6.9.3](https://wordpress.org/news/2026/03/wordpress-6-9-3-and-7-0-beta-4/) is an immediate follow-up with fixes for bugs introduced in 6.9.2. WordPress 6.9.4 later completed incomplete fixes from both releases. See [WordPress 6.9.4](/vulnerability-tracker/2026/03/wordpress-6-9-4).

## Are sites on Pantheon affected?

Yes. WordPress sites running a version before 6.9.2 are affected until you update.

## What Pantheon has done

Pantheon made WordPress 6.9.3 available as a core update on March 10, 2026.

## What you need to do

Update to the latest WordPress release from your Pantheon dashboard or Terminus. See [how to apply core updates](/core-updates#apply-upstream-updates-via-the-site-dashboard).
