## What is the vulnerability?

[WordPress 7.1.5](https://wordpress.org/news/2026/11/wordpress-7-1-5-release/) is a security release that fixes 20 issues in WordPress core. The most serious can be exploited without logging in:

- Privilege escalation through Template Part block attributes, which could lead to remote code execution.
- Stored cross-site scripting (XSS) through shortcode attributes in comments.
- Denial of service through batched XML-RPC pingbacks.
- Private taxonomy terms exposed through the REST API search endpoint.

The other fixes include SQL injection in `WP_Meta_Query` and in Customizer changeset previews, privilege escalation from Administrator to Super Admin on multisite, several stored and reflected XSS issues, authorization bypass, and information disclosure through the REST API and XML-RPC. See the [release note](/release-notes/2026/11/wordpress-7-1-5) for the full list.

## Are sites on Pantheon affected?

Yes. WordPress sites running a version before 7.1.5 are affected until you update.

## What Pantheon has done

Pantheon deployed Web Application Firewall (WAF) protection in advance for some of the vulnerabilities this release fixes. The WAF rules don't replace the update. Pantheon now provides WordPress 7.1.5 as a core update.

## What you need to do

Update your sites to WordPress 7.1.5 as soon as possible. Apply the update from your Pantheon dashboard or with Terminus. See [how to apply core updates](/core-updates#apply-upstream-updates-via-the-site-dashboard).
