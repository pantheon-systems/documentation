## What is the vulnerability?

[SA-CORE-2026-010](https://www.drupal.org/sa-core-2026-010) is an information disclosure vulnerability in the Image module. Image style derivatives stored on file schemes other than the core private scheme could be served without the access checks intended for access-restricted images.

## Are sites on Pantheon affected?

Yes. Drupal 7 sites running a version before 7.106 are affected until you update.

## What Pantheon has done

Pantheon provides Drupal 7.106, which backports the fix, through [long-term support for Drupal 7](/supported-drupal/#drupal-7-long-term-support) with Tag1 Consulting.

## What you need to do

Apply the latest upstream update to your Drupal 7 site. See [how to apply core updates](/core-updates#apply-upstream-updates-via-the-site-dashboard).
