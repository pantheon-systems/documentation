## What is the vulnerability?

WP SAML Auth 2.3.2 fixes vulnerabilities in the `robrichards/xmlseclibs` and `onelogin/php-saml` libraries that the plugin depends on. See the [plugin release notes](https://github.com/pantheon-systems/wp-saml-auth/releases/tag/2.3.2) for details.

## Are sites on Pantheon affected?

[WP SAML Auth](https://wordpress.org/plugins/wp-saml-auth/) is a Pantheon-maintained plugin that you install on your site. It isn't part of the Pantheon platform. Sites that run a version before 2.3.2 are affected.

## What Pantheon has done

Pantheon released WP SAML Auth 2.3.2 with updated dependencies.

## What you need to do

Update the plugin from the WordPress dashboard under **Plugins > Installed Plugins**, or download it from the [WordPress Plugin Repository](https://wordpress.org/plugins/wp-saml-auth/). Later releases include additional fixes, so update to the latest version. See [WP SAML Auth 2.3.4](/vulnerability-tracker/2026/08/wp-saml-auth-2-3-4).
