## What is the vulnerability?

[WordPress 6.9.4](https://wordpress.org/news/2026/03/wordpress-6-9-4-release/) is a security release that addresses incomplete security fixes from the 6.9.2 and 6.9.3 releases. It fixes three vulnerabilities:

- A PclZip path traversal issue.
- An authorization bypass on the Notes feature.
- An XXE (XML External Entity) vulnerability in the external getID3 library.

## Are sites on Pantheon affected?

Yes. WordPress sites running a version before 6.9.4 are affected until you update.

## What Pantheon has done

Pantheon provides WordPress 6.9.4 as a core update.

## What you need to do

Update to WordPress 6.9.4 from your Pantheon dashboard or Terminus. See [how to apply core updates](/core-updates#apply-upstream-updates-via-the-site-dashboard).
