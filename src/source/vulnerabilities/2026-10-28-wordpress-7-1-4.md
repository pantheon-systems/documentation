## What is the vulnerability?

[WordPress 7.1.4](https://wordpress.org/news/2026/10/wordpress-7-1-4/) is a security release that resolves 13 security issues:

- A remote code execution weakness in the upgrade process.
- Stored XSS through specially crafted block markup, privacy data removal requests, Customizer selective refresh, the Categories, Playlist, Image, and Comments pagination blocks, user login fields, and the Interactivity API.
- A stored denial of service in the Interactivity API.
- Unauthenticated disclosure of unpublished Customizer changesets.
- Notes readable by unauthorized privileged users, allowing privilege escalation.

The release also updates the bundled certificates to account for the revocation of an eMudhra root certificate.

## Are sites on Pantheon affected?

Yes. WordPress sites running a version before 7.1.4 are affected until you update.

## What Pantheon has done

Pantheon deployed platform-wide mitigations against external abuse of some of the vulnerabilities this release fixes, and monitors those rules. The mitigations don't replace the update. Pantheon now provides WordPress 7.1.4 as a core update.

## What you need to do

Update to WordPress 7.1.4 as soon as possible from your Pantheon dashboard or Terminus. See [how to apply core updates](/core-updates#apply-upstream-updates-via-the-site-dashboard).
