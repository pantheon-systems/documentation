## What is the vulnerability?

The PHP project released [8.1.34](https://www.php.net/ChangeLog-8.php#8.1.34), [8.2.30](https://www.php.net/ChangeLog-8.php#8.2.30), [8.3.29](https://www.php.net/ChangeLog-8.php#8.3.29), and [8.4.16](https://www.php.net/ChangeLog-8.php#8.4.16) with security fixes, along with bug fixes and enhancements. See the PHP changelogs for the individual fixes.

## Are sites on Pantheon affected?

Sites running an earlier patch release were affected until the platform update reached them.

## What Pantheon has done

Pantheon completed and deployed the updates to the platform on December 23, 2025. PHP 8.4 is available only with [PHP Runtime Generation 2](/php-runtime-generation-2), and the PHP 8.4 upgrade process automatically upgrades your site to PHP Runtime Generation 2 if it isn't already on it.

## What you need to do

No action is needed. PHP 8.1 and 8.2 receive security-only updates. For the best performance and security, Pantheon recommends running PHP 8.2 or later.
