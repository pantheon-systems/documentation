Terminus [4.3.5](https://github.com/pantheon-systems/terminus/releases/tag/4.3.5) is now available. This release points the Terminus account dashboard URL at the dashboard root and changes the default retention for `backup:create` to 30 days.

## Key improvements in this release

- **Shorter default backup retention**: `backup:create` now keeps backups for 30 days by default, previously 365. It also rejects `--keep-for` values above 180 days, below 1, or that are not whole numbers before contacting the API. The temporary backups created by `local:getLiveDB` and `local:getLiveFiles` also now default to 30 days. If your scripts or CI rely on the previous default, pass `--keep-for` explicitly. ([#2934](https://github.com/pantheon-systems/terminus/pull/2934))
- **Account dashboard URL**: The Terminus account dashboard URL now points at the dashboard root. ([#2944](https://github.com/pantheon-systems/terminus/pull/2944))

## How to upgrade to Terminus 4.3.5

If you use Homebrew (macOS-only) to manage your Terminus installation, you should upgrade using:

```shell{promptUser: user}
brew upgrade terminus
```

If you installed Terminus directly from the `.phar` file, you should upgrade using the `self:update` command:

```shell{promptUser: user}
terminus self:update
```

For more information about this release, visit the [GitHub release page](https://github.com/pantheon-systems/terminus/releases/tag/4.3.5).

If you have questions or concerns around Terminus, please use the [Terminus issue queue](https://github.com/pantheon-systems/terminus).
