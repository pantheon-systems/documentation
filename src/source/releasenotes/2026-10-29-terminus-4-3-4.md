Terminus [4.3.4](https://github.com/pantheon-systems/terminus/releases/tag/4.3.4) is now available. This release keeps sensitive option values out of request headers and verbose output, fixes dashboard links for multidev environments, and removes a PHP deprecation warning from `backup:automatic:info`.

## Key improvements in this release

- **Sensitive values kept out of headers and verbose output**: Terminus no longer includes sensitive option values such as `--machine-token`, or the arguments of remote commands, in the command header it sends to Pantheon or in very-verbose (`-vvv`) output. ([#2929](https://github.com/pantheon-systems/terminus/pull/2929))
- **Dashboard links for multidev environments**: Dashboard URLs, such as those from `dashboard:view`, now use the site-redirect route, so links to multidev environments resolve correctly. ([#2930](https://github.com/pantheon-systems/terminus/pull/2930))
- **Fixed deprecation warning in `backup:automatic:info`**: The command no longer prints a PHP deprecation warning when no automatic backup schedule is set. ([#2913](https://github.com/pantheon-systems/terminus/pull/2913))

## How to upgrade to Terminus 4.3.4

If you use Homebrew (macOS-only) to manage your Terminus installation, you should upgrade using:

```shell{promptUser: user}
brew upgrade terminus
```

If you installed Terminus directly from the `.phar` file, you should upgrade using the `self:update` command:

```shell{promptUser: user}
terminus self:update
```

For more information about this release, visit the [GitHub release page](https://github.com/pantheon-systems/terminus/releases/tag/4.3.4).

If you have questions or concerns around Terminus, please use the [Terminus issue queue](https://github.com/pantheon-systems/terminus).
