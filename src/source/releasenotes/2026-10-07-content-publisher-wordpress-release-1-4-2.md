Version 1.4.2 of the [Pantheon Content Publisher](https://wordpress.org/plugins/pantheon-content-publisher/) WordPress plugin is now available.

## What's new?

Smart Components now display in the Content Publisher real-time preview. [#272](https://github.com/pantheon-systems/pantheon-content-publisher-wordpress/pull/272)

Update to 1.4.2 from the WordPress dashboard under **Plugins > Installed Plugins**, or download it from the [WordPress Plugin Repository](https://wordpress.org/plugins/pantheon-content-publisher/).

For more details, see the [plugin changelog](https://github.com/pantheon-systems/pantheon-content-publisher-wordpress/releases).
