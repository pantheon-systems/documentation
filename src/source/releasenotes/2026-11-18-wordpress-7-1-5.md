Pantheon now provides [WordPress 7.1.5](https://wordpress.org/news/2026/11/wordpress-7-1-5-release/), a security release that fixes 20 issues in WordPress core.

## Action required

Update your sites to WordPress 7.1.5 as soon as possible. Apply the update from your Pantheon dashboard or with Terminus. See [how to apply core updates](/core-updates#apply-upstream-updates-via-the-site-dashboard).

Pantheon deployed Web Application Firewall (WAF) protection in advance for some of the vulnerabilities this release fixes. The WAF rules do not replace the update, so update your sites as soon as possible.

## This release fixes 20 security issues

Vulnerabilities that attackers can exploit without logging in:

* Privilege escalation through Template Part block attributes, which could lead to remote code execution.
* Stored cross-site scripting (XSS) through shortcode attributes in comments.
* Denial of service through batched XML-RPC pingbacks.
* Private taxonomy terms exposed through the REST API search endpoint.

Other vulnerabilities:

* SQL injection in `WP_Meta_Query` through nested relation values.
* SQL injection through the front page setting in Customizer changeset previews.
* Privilege escalation from site Administrator to Super Admin on multisite through Customizer menu previews.
* Stored XSS by users with the Contributor role or higher in the Comment Date block, in oEmbed provider responses, and in the block editor through media filenames.
* Stored XSS by Administrators through Customizer previews.
* XSS in `wp_interactivity_data_wp_context()` through the store namespace.
* XSS in the block editor through Openverse image metadata.
* Reflected XSS in the legacy media library popup.
* Authorization bypass by users with the Author role or higher through comment editing in the admin.
* User email addresses exposed to users with the Author role or higher through the REST API comments endpoint.
* Information disclosure by users with the Editor role or higher through post and template author assignment in the REST API.
* Information disclosure by Subscribers through XML-RPC `wp.getComments`.

Hardening changes:

* WordPress now matches JSON media types with a corrected regular expression.
* WordPress removes the block editor's Imgur embed variation, because its server-side provider no longer exists.

This release also removes 1024-bit certificates from the bundled root certificates in WordPress 6.9.12 and earlier. WordPress 7.0 already removed them.

## Dependabot commits in the release history

The release history includes two commits that manage `.github/dependabot.yml`. Pantheon added them by mistake. The first commit adds the file and the next commit removes it, so applying the update makes no net change to your site.

For full details, see the [WordPress 7.1.5 release announcement](https://wordpress.org/news/2026/11/wordpress-7-1-5-release/).
